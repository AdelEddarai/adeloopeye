Analyst Workflow

From raw signal to finished brief

A disciplined pipeline that keeps a full audit trail on every conclusion.

01 · INGEST

Capture & normalize

Streams from public transponder and registry sources are ingested, de-duplicated and normalized into typed records.

02 · ENRICH

Correlate across layers

Automatic entity resolution links a flight track to a registered operator, its ownership chain and its network footprint.

03 · DETECT

Apply detection rules

Rules flag anomalies — squawk switches near borders, extended loitering, AIS gaps — and rank them by risk score.

04 · REPORT

Brief with evidence

Every finding exports with timestamps, source URLs and confidence so the analyst can defend the conclusion.

Engineering

Built on a composable pipeline

const pipeline = adeloop.create({ mode: 'analyst' });

pipeline
  .source('adsb.live') // live flight transponders
  .source('ais.maritime') // vessel positions
  .enrich('entity', { depth: 3 }) // ownership resolution
  .geo() // geospatial correlation
  .detect('evasion') // threat-pattern rules
  .report('pdf', { classify: 'restricted' });

// Output: analyst-ready brief with full evidence chain
